# Module 1: Access Sandbox
 
This module will walk users how to access the Sandbox via the NBDC Data Access Platform (hosted by Lasso).


## Module Objectives

1. Navigate to the LASSO platform
2. Login to the NBDC through the RAS login system.
3. Access the sandbox and review the available tools.

## Walkthrough

1. Navigate to https://nbdc-datashare.lassoinformatics.com/ and select the login button on the lower left hand side of the screen. 
<img src="../images/module1/image1.png" alt="Study Target Progress" width="70%" height="auto" class="center">

2. This should take you to a login screen where you can use federal RAS system for login. Go ahead and use the RAS system to login like
     you normally would. We normally use the login gov but use cases may vary from person to person.
<img src="../images/module1/image2.png" alt="Study Target Progress" width="70%" height="auto" class="center">
<img src="../images/module1/image3.png" alt="Study Target Progress" width="70%" height="auto" class="center">

3. After logging in, you should be able to access the sandbox on the lower left hand corner. You’ll also have access to the help center,
   as well as the study data and search filter.
<img src="../images/module1/image4.png" alt="Study Target Progress" width="70%" height="auto" class="center">

4. The sandbox environment contains multiple applications that we will plan to explore, including: the virtual desktop, the Rstudio Server,
   and the Jupyter Notebook applications – lets start by selecting the “Linux Desktop on ood-pdcluster” , which provides a virtual desktop
   Sandbox environment. The next section :doc:`using_the_desktop_on_the_sandbox` will show how to navigate the virtual desktop.
