<h1><i class="fa-brands fa-codepen"></i> Welcome to the HDCC Sandbox Tutorial Series!</h1>

Large-scale initiatives such as the **HEALthy Brain Child Development ([HBCD](https://hbcdstudy.org/))** and **Adolescent Brain Cognitive Development ([ABCD](https://abcdstudy.org/))** studies generate unprecedented volumes of longitudinal neuroimaging and behavioral data. These datasets create new opportunities to study how brain development interacts with environmental influences across critical early life periods. 

To support data access and analysis, the **[NBDC Data Access Platform](https://nbdc-datashare.lassoinformatics.com/)** provides a centralized portal where researchers can explore, search, and download controlled-access data releases. 

**The [HDCC Sandbox](https://nbdc-safe.lassoinformatics.com/pun/sys/dashboard) extends this platform by providing a *secure, cloud-based analysis environment* where approved users can work with release data directly without needing to download or manage large datasets locally.** **The Sandbox provides:**

- Secure access to controlled NBDC datasets such as HBCD Study data
- A browser-based virtual desktop environment  
- A suite of built-in tools for analysis, including **RStudio** and **Jupyter Notebook**  
- A user-friendly interface suitable for both beginner and advanced users  

This tutorial series will guide you through how to **access the Sandbox environment and use its analysis tools to explore HBCD study data within the NBDC platform.** See the [HBCD Data Release Docs](https://docs.hbcdstudy.org/latest/) for detailed documentation about the latest release data.
